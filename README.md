# Savemedia Android App

Official Android application for Savemedia.online - Download videos from 30+ platforms!

## 🚀 Features

- ✅ Download videos from YouTube, Facebook, Instagram, TikTok & 30+ more platforms
- ✅ Same beautiful UI as savemedia.online website
- ✅ AdMob integration for monetization
- ✅ Multiple quality formats (1080p, 720p, 480p, MP3)
- ✅ Dark mode support
- ✅ Download history
- ✅ Fast and secure downloads

## 📱 Screens

1. **Home Screen** - URL input with security badges
2. **Result Screen** - Video info & format selection  
3. **Download Screen** - Preview & download with ads
